# KodakkattilWebsite

The official website for Kodakkattil Ayurvedics. Built with Next.js, React, and Tailwind CSS.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure
- `app/` - The Next.js App Router for different pages like treatments, specialities, about, stories, and booking.
- `components/` - Reusable UI components.
- `content/` - JSON data files that populate the website's content (e.g. treatments, doctors, testimonials).
- `public/` - Static assets including images and icons.

## Features
- **Dynamic Content:** Treatments, doctors, and testimonials are powered by simple JSON files.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Interactive UI:** Smooth reveal animations, custom sliders, and easy navigation.
